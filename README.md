# EventCart

**Python** · **RabbitMQ** · **Microsserviços** · **Event-Driven Architecture (EDA)** · **Criptografia Assimétrica** · **Assinatura Digital**

> Backend de e-commerce utilizando **microsserviços**, **RabbitMQ** e **Arquitetura Orientada a Eventos**.  
> Projeto prático de **Sistemas Distribuídos**.

A comunicação entre os serviços ocorre exclusivamente por eventos através do RabbitMQ.
